Demo Script: Angular To-Do App ~2 min

Start with browser open to localhost:4200, showing empty to-do list

"So here's our to-do list app running in Angular. Right now it's empty, and you can see it gives us a friendly message saying 'No tasks yet.' Let me add a few things."

Click into the input field, type "Buy groceries", click Add

"I'll type 'Buy groceries' and hit Add. And there it is. Notice how the input clears itself automatically. That's two-way data binding at work. The variable resets to empty and the input updates to match."

Type "Study for finals", press Enter key

"I can also just press Enter instead of clicking the button. Same result."

Type "Walk the dog", press Enter. Type "Do laundry", press Enter.

"Let me add a couple more. And notice down at the bottom, it's tracking how many items are remaining. Right now it says 4 items remaining."

Check the checkbox on "Buy groceries"

"Now if I check off 'Buy groceries', a few things happen. The text gets a strikethrough, it grays out, and the counter drops to 3 items remaining. I didn't write any code to update the DOM. Angular sees the data changed and handles all of that."

Check off "Walk the dog"

"Check off another one. 2 items remaining."

Hover over "Do laundry" to show the X button, then click it to delete

"And if I hover over an item, this delete button appears. If I click it, the item is gone. Angular re-renders the list automatically."

Click into input, show that the Add button is grayed out while input is empty

"One more small thing. See how the Add button is grayed out right now? That's because the input is empty. Angular is checking the value in real time and disabling the button. I didn't write an event listener for that. It's just a property binding on the disabled attribute."

Type a space, show button still disabled, then type "Finish presentation", press Enter

"Even a space won't work, it trims whitespace. But type something real and we're good."

Pause briefly on the final state of the app

"So that's the whole app. Add, complete, delete, input validation. All built with Angular components, two-way data binding, and template syntax. No direct DOM manipulation anywhere."

Tip: Do the actions while you're talking, not in silence. Practice once or twice for pacing.
